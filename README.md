# Movie_Script_with_Age_Rating_by_Pratik_Kalamkar-EN-Hi-Mr

## Verified Movie Scripts with Age_Rating Labels

This repository serves as the central access point for three curated movie-script datasets developed during doctoral research in Automatic Movie Certification and Multilingual Natural Language Processing.

The collection contains full-length movie scripts annotated with verified Age_Rating labels obtained through metadata validation, title normalization, release-year verification, OMDb/TMDb cross-validation, and manual quality assurance.

The datasets support research in:
- Movie Age_Rating Prediction
- Content Moderation
- Long-Document Classification
- Explainable AI (XAI)
- Regulatory NLP
- Multilingual NLP
- Content Severity Analysis

# Dataset Construction

The datasets were assembled from multiple publicly accessible screenplay repositories and movie-script archives, including IMDb-associated screenplay collections, Scripts.com, and additional online sources.

Movie titles, release years, and Age_Rating labels were validated using OMDb, TMDb, supplementary metadata sources, automated consistency checks, and manual review procedures.
